# 🧠 Git, GitHub & GitLab

This section of my **DevOps Journey** is dedicated to mastering **Version Control Systems (VCS)** — specifically **Git**, **GitHub**, and **GitLab**.

---

## 🚀 Overview

Version control is the backbone of every DevOps workflow.  
It helps developers and operations teams collaborate efficiently, track changes, and automate deployments through CI/CD pipelines.

In this section, I’ve documented:
- The **core Git concepts and commands**
- How to use **GitHub** for collaboration and open-source contribution
- How to build and run **GitLab CI/CD pipelines** for real-world automation

---

---

## 🧰 Tools & Technologies

| Tool | Description |
|------|--------------|
| **Git** | Distributed version control system |
| **GitHub** | Cloud-based hosting for Git repositories, collaboration & open source |
| **GitLab** | Complete DevOps platform for version control, CI/CD, and deployment automation |

---

## 🎯 Learning Goals

1. Understand and use **Git commands** for everyday development.
2. Work efficiently with **branches**, **merges**, and **rebases**.
3. Manage repositories and collaboration on **GitHub**.
4. Learn how **GitLab CI/CD** automates build, test, and deploy stages.
5. Create and manage **real pipelines** using `.gitlab-ci.yml`.
6. Integrate **Docker** and **AWS** into GitLab pipelines (coming soon).
