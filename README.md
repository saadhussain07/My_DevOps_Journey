## 📚 Learning Roadmap

### Phase 1 — Foundation ✅
```
Linux basics → Shell scripting → Bash automation
File system, permissions, networking, processes
```

### Phase 2 — Version Control ✅
```
Git core → GitHub workflows → GitLab CI/CD
Branching strategies → GitOps concepts
```

### Phase 3 — Containers ✅
```
Docker basics → Dockerfile → Docker Compose
Image optimization → Container networking
```

### Phase 4 — Orchestration ✅
```
Kubernetes architecture → Pods, Services, Deployments
Helm charts → RBAC → Ingress → HPA
```

### Phase 5 — CI/CD ✅
```
Jenkins pipelines → GitHub Actions → GitLab CI
ArgoCD GitOps → End-to-end deployment automation
```

### Phase 6 — Cloud & IaC ✅
```
AWS (EC2, EKS, S3, RDS, VPC, IAM)
```
